## 📖 About

Most pytest tutorials either stop at `assert True` or assume you already know pytest. This one is different — 28 sections taking you from your first test to shipping a full CI pipeline with coverage, matrix builds, and plugins.

Every example is runnable. Every concept is explained. Nothing is hand-waved.

## ✨ Highlights

- 🎯 **Beginner → advanced** — 28 sections
- 🧪 **100+ runnable examples**
- 🔍 **Covers the gaps** — assertion rewriting, import modes, conftest hierarchy
- 🐛 **"Common errors → fixes"** section
- ⚙️ **Full `pytest.ini` reference**
- 🚀 **CI with GitHub Actions**
- 🎓 **Async, doctests, hooks, custom plugins, Hypothesis**
- 🌗 **Dark mode** + mobile-friendly
